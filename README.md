Animated Shorts Pipeline
A toolkit for making animated Greek mythology shorts for YouTube. Follow the steps in order.
Step 1: Ideas and Script
Use the youtube-agent-skill folder. Pick a topic, write a hook-driven script, and check the title and thumbnail together.
Step 2: Style and Storyboard
Use the stickman-video-director folder. Choose the B8 Greek Mythology style. Approve the script and a short sample first.
Step 3: Voiceover
Record your own voice or use the voiceover in stickman-video-director. For a free voice, use Edge TTS from MoneyPrinterTurbo (github.com/harry0703/MoneyPrinterTurbo).
Step 4: Visuals
Use stickman-video-director again. Use Code Engine for free layered animation, or Model Engine for a cinematic look with a video model.
Step 5: Motion Graphics
Use the bang-motion folder to make an intro, titles, kinetic text and an end bumper.
Step 6: Assembly and Render
The agent combines scenes, captions, music and effects into a finished video file.
Step 7: Publish
Use the title, thumbnail and SEO from youtube-agent-skill, then upload in YouTube Studio.
Step 8: Improve
Use the retention reader in youtube-agent-skill to see where viewers leave, then fix the next script.
